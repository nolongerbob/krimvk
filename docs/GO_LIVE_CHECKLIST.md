# Go-Live Checklist (nic.ru)

## 1. Инфраструктура

- [ ] VPS создан, доступ по SSH по ключу настроен.
- [ ] Выполнен bootstrap сервера (`scripts/bootstrap-vps.sh`) или эквивалент вручную.
- [ ] Nginx установлен и активен, конфиг проверен `nginx -t`.
- [ ] PM2 установлен, автозапуск включен (`pm2 startup` + `pm2 save`).
- [ ] Домен на nic.ru указывает на VPS (A/AAAA записи).
- [ ] SSL выпущен и работает на основном и `www` домене.

## 2. Приложение

- [ ] На сервере заполнен production `.env` по шаблону `.env.example.vps`.
- [ ] `DATABASE_URL` указывает на production БД.
- [ ] Выполнены миграции БД и успешная сборка приложения.
- [ ] `/api/health` отвечает `200`.
- [ ] Основные сценарии вручную проверены (логин, заявки, загрузка файлов).

## 3. CI/CD

- [ ] В GitHub заведены все secrets из `docs/GITHUB_SECRETS.md`.
- [ ] CI workflow на PR проходит.
- [ ] Deploy workflow на `main` успешно выполняется.
- [ ] Rollback-сценарий протестирован хотя бы один раз.

## 4. Безопасность

- [ ] Выполнен чеклист `docs/SERVER_HARDENING.md`.
- [ ] В репозитории нет production секретов.
- [ ] Доступ к БД и серверу ограничен по принципу least privilege.
- [ ] Настроены ротация логов и базовый мониторинг.

## 5. РФ-комплаенс

- [ ] Опубликованы `/legal/privacy`, `/legal/terms`, `/legal/cookies`.
- [ ] Cookie banner работает и сохраняет выбор пользователя.
- [ ] Определен ответственный за ПДн и процесс обработки обращений субъектов ПДн.
- [ ] Проверена локализация хранения/первичной обработки ПДн граждан РФ.

## 6. Эксплуатация

- [ ] Настроены ежедневные backup jobs (БД + uploads).
- [ ] Проверено восстановление из бэкапа.
- [ ] Команда знает runbook: `docs/PRODUCTION_RUNBOOK.md`.
- [ ] Выполнен пошаговый сценарий: `docs/NIC_RU_GO_LIVE_90MIN.md`.
