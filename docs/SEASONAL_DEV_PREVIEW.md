# Осеннее оформление: локальная разработка

Интегрировано в общую оболочку настоящего сайта, не в iframe. Production заблокирован проверкой NODE_ENV; по умолчанию эффект выключен. Публикация не выполнялась.

- `/dev/autumn` — включение и тестовые поверхности без входа и данных абонентов.
- На главной листья и капелька ограничены картинкой хиро: листья оседают у её нижнего края, персонаж размещается справа снизу и не следует за посетителем в следующие секции. Отдельная дорожка и панель под футером на главной не добавляются. Полный режим капельки и панель остаются на `/dashboard` и вложенных страницах кабинета. На остальных маршрутах — только капелька-кнопка справа снизу, без листопада, дорожки, сгребания и ветра. При переходе на них осенняя сцена уничтожается; отдельный локальный цикл чередует спокойную позу, два прыжка, пиксельные пузыри и радостную эмоцию. В скрытой вкладке время действий не продвигается; reduced motion оставляет неподвижный кадр. Общий локальный DEV-переключатель пока управляет обоими режимами.
- `/admin/site-settings` — тот же переключатель внутри защищённой админки.
- Настройка хранится в localStorage только этого браузера. Это не глобальная серверная настройка.

## ИИ-помощник (только DEV)

Публичная база сценариев: `lib/visitor-assistant-knowledge.ts` — 14 тем с путями к исходным формам для проверки при изменениях сайта. Покрывает регистрацию и письма, два вида паролей, привязку и ошибки лицевых счетов, передачу и исправление показаний, квитанции, оплату, профиль, поддержку, подключение и аварии. Передаётся модели целиком на сервере; внутренние статьи админки и клиентские данные не используются. Проверенные ответы не означают доступ модели к счёту. Модель всё ещё может ошибаться, поэтому важные ответы проверяются отдельно; планы не считаются работающими функциями.

Облачко над каплей открывает чат. `/api/assistant/chat` использует DeepSeek с отдельным публичным контекстом, без административных шаблонов, чужой переписки и данных лицевых счетов. Ключ остаётся на сервере; в клиент отправляется только ответ. Есть ограничение длины истории, таймаут 25 секунд, максимум два параллельных запроса, 20 запросов в минуту и 200 в день на процесс. Эти лимиты для локальной разработки, перед публичным запуском нужны общие лимиты и защита от злоупотреблений. Перезапуск процесса сбрасывает лимиты.

Обычный launcher отключает DeepSeek. Флаг `--assistant` разрешает только `DEEPSEEK_API_KEY`, переданный в окружение процесса; ключи из файлов `.env` не подхватываются. База, 1С, письма и хранилище остаются отключены. Не сохранять ключи в репозитории. Для Node 24 при ошибке загрузки Tailwind TS использовать `NODE_OPTIONS=--no-experimental-strip-types`.

Кнопка оператора передаёт историю в существующую авторизованную ручку обращений только при `ASSISTANT_TEST_SUPPORT_ENABLED=true` в отдельной тестовой среде. При `SEASONAL_DEV_DIST=1` передача всегда заблокирована. После подтверждённой передачи ответы оператора доступны по ссылке в обычной переписке ЛК, не внутри ИИ-виджета. На изолированном стенде показано честное сообщение о недоступности; ложное ожидание оператора не создаётся. Схема БД и административные права не менялись. Все новые ручки возвращают 404 вне development.
- `node scripts/dev-seasonal.mjs` запускает Next dev на loopback, порт 3005, в отдельной директории сборки. Значения интеграций из env-файлов нейтрализованы; рабочая БД, 1С, письма и хранилище не используются. Вход и страницы с данными БД на этом изолированном запуске недоступны.
- Проверки: TypeScript и тесты переключателя/жизненного цикла. Визуальная проверка интеграции в браузере остаётся ручной.

Актуальный стенд: `http://127.0.0.1:3005/dev/autumn`. Старый отдельный макет на порту 4173 не содержит обновлений интеграции.

Опора персонажа следует за нижним краем окна, но поднимается перед футером, чтобы не заходить на него. Напольные листья следуют за той же опорой; листья на карточках остаются привязаны к карточкам. При изменении ширины свободные листья перемещаются пропорционально ширине окна. Прокрутка и изменение размеров сами по себе не запускают сжатие. При столкновении с защищённым блоком капелька превращается в лужицу; перетекание разрешено только по свободному горизонтальному пути на той же опоре. Если пути нет, она остаётся лужицей, без телепортации. Из свободного укрытия периодически сдувает листья, пока препятствие не освободится. Тесты проверяют эти переходы, изменение высоты окна и ограничение перед футером.

Анимация отключается для BVI и reduced-motion; при скрытой вкладке движение приостанавливается. Листопад не принимает клики; текст, кнопки и содержимое выбранных поверхностей маскируются. Смена маршрута удаляет старую сцену и обработчики. Помощник — только диалог-заглушка, без ИИ и отправки сообщений.

## Графика

`public/images/seasonal/kapelka-drag.webp` — шесть кадров переноски, созданы встроенным ImageGen (не CLI), преобразованы в lossless WebP. Промпт: same reference cute flat coarse pixel-art blue droplet, yellow farmer hat, black outline, pink cheeks; transparent 3×2 sheet; six separate connected silhouettes: surprised O-mouth dangling legs, limbs swinging left, alternate kick right, blink, delighted smile and raised arms, relaxed landing; no rake, leaves, scenery, text, glow or 3D. Кадры проверены после выделения alpha-силуэтов на белом фоне. При перетаскивании позы переключаются, наклон зависит от движения, отпускание запускает плавное перетекание, а не замену координат. Хэдер полностью исключён из поиска свободных мест; переноска ограничена его нижней границей.

Персонажа можно переносить мышью или касанием: после порога 5 px включается покачивание, зависящее от горизонтального движения; отпускание выбирает свободный край близкой карточки либо безопасное место. Клик после перетаскивания не открывает помощника. Ручная посадка на карточку сохраняется при прокрутке. Автоматический поиск предпочитает доступный нижний правый угол и проверяет другие достижимые места, а не одну ближайшую точку. Перетекание ускорено до 280 px/s и рисуется пиксельной струйкой с последующим восстановлением формы. Выдохи разделены 60 секундами, грабли показываются только при сборе напольных листьев.

Поиск укрытия учитывает свободное пространство внутри карточек: их фон не обрезает персонажа. Препятствия для укрытия — реальные строки текста, элементы управления и изображения. Сначала ищется место на текущей высоте; если его нет — место выше с проверенным маршрутом для лужицы. В укрытии используется анимация сдувания. Это расширяет первоначальное ограничение только горизонтального перетекания; произвольного перемещения стоящего персонажа нет.

`public/images/seasonal/kapelka-autumn.webp` — спрайт, созданный встроенным ImageGen по утверждённому образу. Технически преобразован в WebP. При загрузке восемь связанных силуэтов выделяются по alpha-каналу, чтобы пересекающиеся границы прямоугольников не захватывали соседние грабли.

Промпт: flat cute black-outline pixel-art blue water droplet, short bent tip, yellow farmer straw hat, brown band, pink cheeks, hands, feet and rake; transparent background; four walking-right poses and four raking poses (reach, lower, pull, lift), consistent scale and baseline, no text, borders or scenery, 2D not 3D.

`public/images/seasonal/kapelka-liquid.webp` — дополнительный лист из шести поз, созданный ImageGen по тому же образу. Промпт: cute flat 2D 8-bit black-outline blue water droplet in yellow straw hat; transparent 3×2 sheet; standing empty-handed, half-squashed, flat puddle, inhaling with puffed cheeks, exhaling to the right, relaxed; no rake, no detached objects; consistent scale and separate silhouettes. Кадры выделяются по alpha-каналу и выравниваются по нижней точке тела.

Перед production нужны отдельные приёмочные проверки на реальных страницах, мобильных устройствах и BVI, а также проектирование общей серверной настройки с правами администратора. Текущая локальная настройка не предназначена для управления всеми посетителями.
