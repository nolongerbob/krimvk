# Server Hardening Checklist (nic.ru VPS)

## 1. Доступ и SSH

- Создать отдельного deploy-пользователя (без прямого root-логина).
- Отключить парольный вход по SSH (`PasswordAuthentication no`), оставить ключи.
- Ограничить root login (`PermitRootLogin no`).
- Сменить стандартный SSH-порт при необходимости и зафиксировать в документации.
- Включить `AllowUsers` только для нужных аккаунтов.

## 2. Firewall и защита от brute force

- Включить `ufw`:
  - allow `22/tcp` (или ваш SSH-порт),
  - allow `80/tcp`,
  - allow `443/tcp`,
  - deny incoming by default.
- Установить и настроить `fail2ban` для `sshd` и `nginx`.

## 3. Обновления ОС и пакетов

- Включить регулярные security updates (`unattended-upgrades`) или расписание ручных.
- Обновлять `nginx`, `nodejs`, `openssl` и системные библиотеки по графику.

## 4. Nginx и TLS

- Принудительный HTTPS и HSTS.
- Минимум TLS 1.2+, отключить устаревшие протоколы.
- Проверять `nginx -t` перед перезагрузкой.
- Проверять валидность сертификата и автообновление certbot.

## 5. Приложение и процессы

- Использовать `NODE_ENV=production`.
- Запускать приложение только через `pm2` с автозапуском после reboot.
- Логи приложения и nginx ротировать (`pm2-logrotate`, `logrotate`).
- Ограничить права на директории приложения и uploads.

## 6. Секреты и доступ к данным

- Не хранить секреты в git.
- Хранить production env только на сервере с ограниченными правами доступа.
- Ротировать ключи при инцидентах/компрометации.
- Ограничить доступ к БД по IP/сетям и минимуму прав пользователя БД.

## 7. Резервное копирование и восстановление

- Ежедневные бэкапы БД и uploads.
- Хранение бэкапов на отдельном носителе/хранилище.
- Ежемесячная проверка процедуры восстановления.

## 8. Контроль перед go-live

- Защита от атак: [WEB_SECURITY.md](./WEB_SECURITY.md) и `sudo bash scripts/harden-vps.sh`
- `/api/health` отвечает стабильно.
- CI и deploy workflow проходят без ошибок.
- Юридические страницы доступны: `/legal/privacy`, `/legal/terms`, `/legal/cookies`.
- Cookie banner отображается новым пользователям и фиксирует выбор.
